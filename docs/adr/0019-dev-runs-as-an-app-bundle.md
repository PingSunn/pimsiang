# Development runs PimSiang as a signed `.app` bundle

macOS lists a program under Privacy and Security only when it has a bundle identity, and attributes a bare binary's permissions to the app that launched it (the terminal, or an agent shell). Run from a terminal, PimSiang never appeared in the Microphone, Accessibility or Input Monitoring panes. `scripts/bundle-dev.sh` now builds `target/PimSiang.app` (identifier `com.pingsunn.pimsiang`, `LSUIElement`, `NSMicrophoneUsageDescription`) around the debug binary and signs it; `scripts/run-dev.sh` builds and `open`s it, passing the model directory with `--env`. `run-dev.sh --plain` keeps the old direct run. The bundle is signed with the self-signed "PimSiang Self-Signed" identity that `scripts/make-signing-cert.sh` creates once in the login keychain (the same identity ADR 0007 uses for releases), so grants survive rebuilds: the grant is tied to the signature, and an ad-hoc signature changes every build. `PIMSIANG_SIGN_IDENTITY` overrides the identity; without the certificate the script falls back to ad hoc and warns on stderr that grants reset each rebuild. `run-dev.sh` quits a running PimSiang before `open`, because `open` on a running app only brings it forward and ignores the new build and `--env`. Before asking, the controller calls the request APIs (`AXIsProcessTrustedWithOptions` with the prompt option, `CGRequestListenEventAccess`, `AVCaptureDevice requestAccess`) so macOS adds the entry itself. Accessibility shows only the system prompt on the first click and opens its pane on the next one, so two windows never appear at once; Input Monitoring requests and then opens its pane. When the executable is not inside a `.app`, the setup window says the permissions belong to the launching terminal.

## Considered options

- **Keep running the bare binary:** grants attach to the terminal, and PimSiang is never listed.
- **Ad-hoc signing only:** every rebuild invalidates the grants and the user re-grants three permissions each time.
- **Wait for the release bundle script (ADR 0007):** blocks onboarding work on packaging that comes later.
